# Кабанбот

Telegram-бот для групп: делает пересказ переписки (`/summary` ответом на сообщение, с которого начать) и зовёт всех по `@all`. Админы групп могут подключить свои модели — OpenRouter, Gemini или любой OpenAI-совместимый API — прямо в личке с ботом.

## Установка

1. **Создайте бота** у [@BotFather](https://t.me/BotFather) и возьмите токен. Там же выключите privacy mode (`/setprivacy` → Disable), иначе бот не увидит сообщения группы.
2. **Заполните `.env`:**
   ```sh
   cp .env.example .env
   ```
   - `BOT_TOKEN` — токен от BotFather.
   - `LLM_PROVIDER`, `LLM_API_KEY`, `LLM_MODEL` (и `LLM_BASE_URL`, если нужен) — модель по умолчанию для групп, где не выбрана своя.
   - `OWNER_ID` — ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot)). Только вашим провайдерам разрешено ходить на локальные адреса, например к своему серверу с моделью.
   - `ALLOWED_GROUPS` — ID групп через запятую, если бот должен работать только в них.
   - `MASTER_KEY` — см. ниже.
3. **Запустите:**
   ```sh
   docker compose up -d --build
   ```
   База лежит в `./data`. Без Docker: `make run` (нужен Go из `go.mod`).
4. **Добавьте бота в группу.** Лучше сделать его администратором: тогда меню `/settings` видит только вызвавший его админ, а не вся группа.

## MASTER_KEY

Ключ, которым шифруются API-ключи провайдеров, подключённых пользователями. Без него бот работает только с моделью по умолчанию, а кнопка «Подключить провайдера» неактивна.

Сгенерируйте 32 случайных байта в base64:

```sh
openssl rand -base64 32
```

или без openssl:

```sh
head -c 32 /dev/urandom | base64
```

Вставьте результат в `.env`: `MASTER_KEY=...`. Храните его вместе с базой. Если ключ потерять или поменять, сохранённые ключи провайдеров расшифровать не получится, и пользователям придётся ввести их заново.

## Команды

- `/summary` ответом на сообщение в группе — пересказ с этого сообщения до конца. Бот видит только сообщения, отправленные после его добавления.
- `/settings` в группе — включить или выключить бота и функции, выбрать модель (только для админов группы).
- `/start` или `/settings` в личке — свои модели и группы, где вы админ.
