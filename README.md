# Кабанбот

Telegram-бот для групп: делает пересказ переписки (`/summary` ответом на сообщение, с которого начать) и зовёт всех по `@all`. Модели для пересказов подключаются в личке с ботом: OpenRouter, Gemini или любой OpenAI-совместимый API.

## Установка

1. **Создайте бота** у [@BotFather](https://t.me/BotFather) и возьмите токен. Там же выключите privacy mode (`/setprivacy` → Disable), иначе бот не увидит сообщения группы.
2. **Заполните `.env`:**
   ```sh
   cp .env.example .env
   ```
   - `BOT_TOKEN` — токен от BotFather.
   - `MASTER_KEY` — обязателен, см. ниже.
   - `OWNER_ID` — ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot)). Владелец может сделать своего провайдера общим для всех групп, и только его провайдерам разрешено ходить на локальные адреса, например к своему серверу с моделью.
   - `ALLOWED_GROUPS` — ID групп через запятую, если бот должен работать только в них.
3. **Запустите:**
   ```sh
   docker compose up -d --build
   ```
   База лежит в `./data`. Без Docker: `make run` (нужен Go из `go.mod`).
4. **Подключите модель.** Напишите боту в личку `/start` → «Мои модели» → «Подключить провайдера», добавьте модель и нажмите «Проверить». Чтобы её могли выбрать админы любых групп, отметьте провайдера «Общий для всех групп».
5. **Добавьте бота в группу** и выберите модель: `/settings` → «Модель». Пока модель не выбрана, `/summary` не работает. Бота лучше сделать администратором: тогда меню `/settings` видит только вызвавший его админ, а не вся группа.

## MASTER_KEY

Ключ, которым шифруются API-ключи провайдеров. Без него бот не запустится.

Сгенерируйте 32 случайных байта в base64:

```sh
openssl rand -base64 32
```

или без openssl:

```sh
head -c 32 /dev/urandom | base64
```

Вставьте результат в `.env`: `MASTER_KEY=...`. Храните его вместе с базой. Если ключ потерять или поменять, сохранённые ключи провайдеров расшифровать не получится, и их придётся ввести заново.

## Команды

- `/summary` ответом на сообщение в группе — пересказ с этого сообщения до конца. Бот видит только сообщения, отправленные после его добавления.
- `/settings` в группе — включить или выключить бота и функции, выбрать модель (только для админов группы).
- `/start` или `/settings` в личке — свои модели и группы, где вы админ.
